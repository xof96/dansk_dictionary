# ADR 0004: mantener derechos reservados durante la beta

- Estado: aceptada.
- Fecha: 2026-09-13.
- Alcance: código y contenido editorial propio.

## Contexto

DD-9 requiere una decisión explícita sobre la licencia del código y de las traducciones y ejemplos
pedagógicos creados para Dansk Dictionary. Esta decisión no puede extenderse a contenido de
terceros, que conserva sus condiciones y atribuciones originales.

## Decisión

Durante la beta no se publicará una licencia para el código ni para el contenido editorial propio.
No se añadirá un archivo `LICENSE` y todos los derechos sobre esos materiales permanecerán
reservados. La publicación del repositorio, si ocurre, no debe interpretarse como autorización para
copiar, modificar o redistribuir esos materiales.

El contenido reutilizado de Wiktionary permanece separado y sujeto a CC BY-SA 4.0/GFDL. Las
dependencias, fuentes, iconos y otros medios conservan sus licencias individuales.

## Consecuencias

Antes de permitir reutilización externa se deberá adoptar otra decisión expresa y añadir la licencia
correspondiente. La interfaz y la documentación de la beta indican el estado actual sin presentar
todo el producto como CC BY-SA.
